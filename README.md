# Coffee-Sales-Dashboard-Excel
## Project Overview  
An interactive Coffee Sales Dashboard created in Microsoft Excel to analyze sales performance, customer behavior, and profitability.  
## Project Note
This project is based on the [Mo Chen YouTube Video](https://www.youtube.com/watch?v=m13o5aqeCbM)
The dashboard structure and main workflow were recreated by following the tutorial.  
I independently added the KPI cards and Profit chart to extend the dashboard and practice creating additional analyses in Excel.

## Skills Used 
- Working with Multiple Worksheets
- Pivot Tables
- Pivot Charts
- XLOOKUP
- INDEX + MATCH
- Slicers
- Timeline Controls
- KPI Cards
- Dashboard Design
  
## Dashboard
The dashboard includes:

- Total Sales
- Total Profit
- Total Orders

- Distinct Customers

- Total Sales Over Time

- Sales by Country

- Top 5 Customers

- Total Profit by Coffee Type 

- Interactive filtering with slicers and timeline
